# José Barber Shop — demonstração

Site estático para apresentação em portfólio.

## Recursos da demonstração

- Layout responsivo com informações e imagem da barbearia.
- Formulário de solicitação de horário que monta uma mensagem e abre o WhatsApp `+55 61 99449-8081`.
- O horário não é confirmado automaticamente: a barbearia confirma a disponibilidade pelo WhatsApp.

Esta versão não inclui consulta de agenda em tempo real nem painel administrativo. O código do site original permanece em um repositório privado.
